# Frontmatter

本目录保存论文前置固定页。

- `cover.docx`：学校官方毕业设计论文封面模板，保留原版式和字段占位。
- `authorization.doc`：学校官方学位论文出版授权书模板，保留原正文、缩进和签名位置。
- `copyright.doc`：学校官方毕业设计（论文）、学位论文版权使用授权书模板，保留原正文、缩进和签名位置。
- `*.pdf`：由构建脚本从 Word 源文件导出的中间产物，不纳入 Git 跟踪。

实际使用时，只需要在这些 Word 文件中填写个人信息，并保持 `frontmatter.json` 中的文件名一致。运行 `.\scripts\build.ps1` 后，构建脚本会自动导出 PDF 并合并进最终论文。
